Premiere Pro Caption Kit — Cheat Sheet

Vaporswift Media · free build · keep at your desk · values for 1080×1920 vertical

The 3-click caption system

  1. Transcribe — Window → Text → Transcribe Sequence (free, on-device).
  2. Create Captions — from transcript. Set short line length for 1–3 words/line.
  3. Apply Track Style — pick your saved style; all captions update. Add scale-pop preset.

Build the style once in Essential Graphics → Track Style dropdown → Create Style. It's then permanent and one-click on every project.

Style 1 — Bold Karaoke Highlight

FontMontserrat ExtraBold / TheBoldFont — ALL CAPS
Size115–130 px
Fill colorWhite #FFFFFF
Highlight colorYellow #FFE000 or Green #36F000 (pick one accent)
Stroke / edgeBlack #000000, 12–16 px
ShadowBlack, opacity 75%, angle 135°, distance 8, blur 12
PositionCentered; ~58–62% down; max width ~80%
AnimationScale 92% → 106% → 100% over 6–8 frames

Style 2 — Clean Minimal White

FontInter SemiBold / Montserrat SemiBold — Sentence case
Size72–85 px
Fill colorWhite #FFFFFF
StrokeOff (or 2 px black on bright footage)
ShadowBlack, opacity 60%, distance 5, blur 14 (soft)
BackgroundOptional black pill @ 28% opacity, high corner radius
PositionCentered; ~80% down (lower third); 1–2 lines
AnimationOpacity 0→100% + rise 20px over 8 frames
Per-word karaoke (Premiere can't auto-do it): use the free word-by-word reveal (short captions + scale pop), a free CapCut round-trip, or build the After Effects karaoke .mogrt (Range Selector → Based On: Words → Fill Color).

Bar RevealAccent bar scales 0→100% (anchor left), text fades, bar exits

Mic cleanup chain (Essential Sound — tag as Dialogue)

  • Reduce Noise ~4–6 · Reduce Rumble on · DeHum if buzzing
  • EQ: Vocal Enhance / boost ~3–5 kHz · Dynamics ~5–7 (the "radio voice")
  • Loudness: Auto-Match. Save as preset → reuse on every clip.

Export — Reels / TikTok / Shorts

Format / ResH.264 · 1080×1920 · frame rate = match source
BitrateVBR 2-pass · target 16 Mbps · max 24 Mbps
AudioAAC 320 kbps, 48 kHz · normalize to −14 LUFS

Free fonts (= the "premium" pack fonts)

Montserrat · Poppins · Anton · Bebas Neue · Inter · Outfit · TheBoldFont — all free (Google Fonts / dafont). Restart Premiere after install.

Avoid pirated pack mirrors (psdly, xtemplates, gfxplugin, intro-hd, freevideoeffect, gfxlife) — cracked motion-graphics files are a common malware vector. Build your own, or buy direct.
