# Premiere Pro Caption & Asset Kit (Free Build)

A do-it-yourself replacement for paid short-form packs (Sparvol Caption FX, MotionText
Pro, etc.). Built for **Adobe Premiere Pro, no After Effects required**, using only
native features + free assets.

Goal: **drag-and-drop captions and assets that cut your editing time**, the way the paid
packs promise — but free, fully customizable, and yours to reuse forever.

---

## What's in this kit

| File | What it gives you |
|------|-------------------|
| `captions/caption-styles.md` | Exact specs (font, size, color, stroke, shadow) for the caption looks you wanted: **Bold Karaoke Highlight** and **Clean Minimal White** |
| `captions/build-and-reuse-workflow.md` | The core speed system: transcribe → style → **save as Track Style** → one-click reuse on every project. Plus the honest truth on per-word karaoke and the free workarounds. |
| `assets/hook-title-cards.md` | Animated "hook" opening title templates for the first 2 seconds, built as reusable `.mogrt` |
| `assets/animated-icons-and-sfx.md` | Drag-and-drop arrows/underlines/scribbles + a free sound-FX library + a mic-cleanup preset chain |
| `export/social-export-presets.md` | Exact export settings for Reels/TikTok/Shorts (resolution, bitrate, loudness) |
| `resources/free-fonts-and-sources.md` | Free fonts that match the "premium" pack fonts, plus vetted free asset sources |

## The 60-second mental model

The paid packs are really selling **three** things. Here's the free equivalent of each:

1. **Styled captions** → Premiere's **Captions + Track Styles** (100% native, free). This is
   the real drag-and-drop win.
2. **Animated text / hooks / icons** → **Motion Graphics Templates (`.mogrt`)** you build
   once and reuse. Also native.
3. **Sound design + export polish** → free SFX libraries + Premiere's **Essential Sound**
   presets + a saved **export preset**.

You don't need to buy any of it. You need it set up *once*. That's what this kit does.

---

## Quick start (do this first)

1. Read `captions/build-and-reuse-workflow.md` — it's the backbone.
2. Install the free fonts from `resources/free-fonts-and-sources.md`.
3. Build your first **Track Style** using `captions/caption-styles.md`.
4. From then on, captioning a new video is: **Transcribe → Create Captions → apply your
   Track Style → done.** Seconds, not minutes.

---

## Honest scope note

This kit is documentation + exact build recipes + sourcing — not pre-built binary `.mogrt`
files (those have to be authored inside Premiere/After Effects on your machine and can't be
generated as text). Everything here is written so you can build the full library yourself in
an afternoon, and it will be *better* than a paid pack because it's tuned to your brand and
costs nothing to extend.
