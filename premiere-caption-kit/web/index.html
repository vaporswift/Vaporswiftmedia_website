The 3-click caption system

Set up once. After that, captioning any video is seconds — the same outcome the paid "one-click caption system" sells.

  1. Transcribe — Window → Text → Transcribe Sequence. Free, on-device, offline.
  2. Create Captions — generates a synced caption track. Set short line lengths for the punchy 1–3-word look.
  3. Apply your Track Style — pick your saved style from the dropdown; every caption updates at once. Add the scale-pop preset and you're done.
The honest catch: native Premiere styles captions as whole blocks — it can't auto-recolor just the spoken word. For that true 2-color karaoke look, use the free word-by-word reveal, a CapCut round-trip, or the After Effects template below.

The After Effects upgrade: true karaoke

The one thing Premiere can't do alone. Build it once in After Effects, export a .mogrt, and it's drag-and-drop in Premiere with editable text and colors.

How it works

A text layer + a Range Selector set to Based On: Words drives the Fill Color. Move the selection across the line word-by-word (tap a marker per beat) and the highlight sweeps with the speech.

The smart workflow

Use native Track Styles for the bulk of talking, and the karaoke .mogrt for hero lines — the hook, the punchline, the CTA — where the highlight earns its keep.
